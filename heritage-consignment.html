Summary

1965 Park Industries presentation lighter engraved to WOC Arthur P. Lancy Jr., Fort Wolters, Texas, Class 65-9WA. Supporting external sources include the VHPA Class 65-9W photograph, the VHPA handwritten roster/name list showing “Lancy,” and a later Tropic Lightning News Air Medal listing for WO Arthur P. Lancy, Co. B, 25th Avn. Bn.
