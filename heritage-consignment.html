Provenance Summary

The provenance connection is supported by three separate evidence categories: the physical lighter inscription, the VHPA class photograph/name-list set, and the later Tropic Lightning News Air Medal listing.


  • Physical object: front Class 65-9WA / Hughes marking and reverse inscription naming WOC Arthur P. Lancy Jr.
  • Class evidence: VHPA WOC Class Pictures Archive, Class 65-9W photograph, and Class 65-9 R/W handwritten roster/name list showing “Lancy.”
  • Later service evidence: Tropic Lightning News, Vol. 2 No. 13, April 3, 1967, Page 2, “Decorated” / Air Medal subsection listing WO Arthur P. Lancy, Co. B, 25th Avn. Bn.

Condition Note

Visible condition from current photographs shows age-consistent surface wear and intact exterior engraving. Consignor reports that the lid opens cleanly, the hinge feels firm, the striker wheel turns, and the insert is present. The lighter does not currently spark because no flint is installed; it has not been cleaned, fueled, or serviced for operation.

Class Designation Note

The lighter is engraved “Class 65-9WA.” The VHPA source image is labeled 65-9W, while the handwritten name list is marked Class 65-9 R/W. This packet presents those items as related class-designation evidence and leaves final catalog wording to specialist review.
